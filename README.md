# Скрипт для практической работы № 4
Скрипт выполняет следующие действия:

Загружает данные из Excel-файла.
Отбирает временной ряд для Malaysia.
Проверяет, что ряд содержит не менее 15 уровней.
Рассчитывает описательные статистики.
Строит графики исходного ряда.
Рассчитывает автокорреляции и строит коррелограмму.
Проверяет стационарность ряда с помощью теста Дики-Фуллера.
Выполняет тест Льюнга-Бокса на наличие автокорреляции.
Проводит декомпозицию временного ряда.
Определяет аномальные уровни.
Выполняет сглаживание временного ряда.
Строит линейную, квадратичную и экспоненциальную модели тренда.
Сравнивает модели по метрикам качества.
Сохраняет таблицы, графики и итоговый JSON-файл с результатами.
